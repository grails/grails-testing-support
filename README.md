Grails testing support has been split and relocated to the following repositories: 
* grails-gorm-testing-support - [grails-data-mapping](https://github.com/grails/grails-data-mapping)
* grails-test-support - [grails-core](https://github.com/grails/grails-core)
* grails-web-testing-support - [grails-gsp](https://github.com/grails/grails-gsp)
* docs - [grails-doc](https://github.com/grails/grails-doc)

the gh-pages branch is used to redirect all https://testing.grails.org/ URLs to https://grails.apache.org/docs-legacy-testing/
